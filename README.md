# Дом рядом — доска объявлений об аренде жилья

Небольшое одностраничное приложение на Vue 3. В нём можно искать жильё, фильтровать объявления, открывать подробную информацию и сохранять понравившиеся варианты.

## Самый простой показ в колледже — без установки и интернета

Скопируйте файл `Открыть_без_интернета.html` на флешку вместе с проектом. На компьютере колледжа откройте его двойным щелчком в браузере. Внутри уже находятся приложение и фотографии: ничего устанавливать и подключать к интернету не нужно.

Если меняете код и хотите заново создать этот файл, на своём компьютере выполните `npm run build`. Команда обновит папку `dist` и файл `Открыть_без_интернета.html`.

## Как запустить исходный проект на компьютере с Node.js

1. Установите **Node.js LTS** с официального сайта: https://nodejs.org/
2. Откройте папку проекта в VS Code.
3. Откройте меню **Терминал → Новый терминал**.
4. Один раз выполните команду `npm.cmd ci` (понадобится интернет).
5. Для запуска приложения выполните `npm.cmd run dev`.
6. Откройте в браузере адрес, который покажет терминал (обычно `http://localhost:5173`).

Чтобы остановить приложение, нажмите `Ctrl+C` в терминале.

Команды здесь указаны для Windows. `npm.cmd` помогает избежать ошибки PowerShell «выполнение сценариев отключено». На Linux и macOS используйте `npm` вместо `npm.cmd`. В архиве нет `node_modules`: для показа готового HTML эта папка не нужна, а для работы с исходниками её создаёт команда `npm.cmd ci`.

Проверка логики: `npm.cmd test`. Обновление готового HTML после изменения кода или данных: `npm.cmd run build`. Подробный порядок показа и объяснение кода находятся в `ЗАЩИТА_ПРОЕКТА.txt`.

## Что можно показать

- поиск по названию;
- фильтры по максимальной цене, количеству комнат и району;
- число объявлений, подходящих под условия;
- добавление в избранное и переключение на избранные объявления;
- подробная карточка объявления;
- сообщение, когда ничего не найдено;
- аккуратное отображение карточек, даже если у объявления нет фотографии или части данных.

## Как проверить парсер

В папке проекта выполните `npm run parse`. Скрипт прочитает сохранённый пример страницы `sample-listings.html`, найдёт в ней структурированные данные JSON-LD, преобразует их в единый формат и запишет результат в `src/data/parsed-listings.json`. Приложение использует эти объявления вместе с дополнительными демонстрационными вариантами.

Это демонстрация разбора уже сохранённой HTML-страницы. Сайты объявлений могут менять разметку и ограничивать автоматические запросы, поэтому приложение не загружает реальные объявления с Avito или Циан. Для подключения конкретного сайта нужны разрешённый источник данных и отдельная проверка его правил.

Важно для сдачи: `sample-listings.html` — искусственный учебный пример, а не страница, скачанная с сайта недвижимости. Если преподаватель требует именно данные настоящего сайта, эта часть задания пока выполнена не полностью. Не называйте этот скрипт работающим парсером Авито или Циан.

Избранное хранится в памяти текущей страницы и очищается при её перезагрузке.

## Как устроен проект

- `src/App.vue` — экран приложения, фильтры, избранное и подробная карточка.
- `src/data/listings.js` — стартовые демонстрационные объявления.
- `scripts/parse-listings.mjs` — небольшой парсер JSON-LD.
- `sample-listings.html` — сохранённый учебный пример страницы с данными.
- `src/style.css` — оформление и адаптация под телефон.
- `public/photos/` — фотографии, включённые в офлайн-проект.
- `Открыть_без_интернета.html` — готовая версия для запуска двойным щелчком без интернета.

## Как объяснить работу приложения

> Приложение написано на Vue. Объявления хранятся в массиве объектов: у каждого объекта есть название, цена, район, комнаты, площадь, описание и фотография. На странице `v-for` показывает карточку для каждого объявления. Поля поиска и фильтров связаны с данными через `v-model`. Вычисляемое свойство `filteredListings` проверяет каждое объявление и оставляет только подходящие. Поэтому одновременно обновляются список и счётчик. Избранное хранится в массиве идентификаторов объявлений, а подробная информация открывается в отдельном окне. Отдельная команда `npm run parse` показывает, как из сохранённой HTML-страницы можно извлечь JSON-LD и привести его к формату приложения.
