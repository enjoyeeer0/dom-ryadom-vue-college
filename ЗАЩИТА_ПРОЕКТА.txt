ДОМ РЯДОМ — ПОДГОТОВКА К ЗАЩИТЕ

1. ЧТО ВЗЯТЬ С СОБОЙ

Отправьте себе архив Проект_для_колледжа.zip. Сохраните копию на флешке.
В колледже скачайте архив, нажмите правой кнопкой → «Извлечь всё».
В извлечённой папке откройте Открыть_без_интернета.html двойным щелчком.
Используйте современный Chrome, Edge или Firefox.
Для этого способа не нужны интернет, Node.js и VS Code.

Исходники тоже лежат в архиве. Если преподаватель захочет запуск из кода,
понадобятся Node.js, интернет для установки зависимостей и терминал в папке:
  npm.cmd ci
  npm.cmd run dev
Откройте адрес, напечатанный в терминале. Для остановки нажмите Ctrl+C.

2. ПОКАЗ ЗА 2–3 МИНУТЫ

— В начале видно 8 объявлений.

Избранное очищается при обновлении страницы. Это простой массив в памяти.

3. КОРОТКИЙ РАССКАЗ СВОИМИ СЛОВАМИ

Это одностраничное приложение на Vue 3. Оно показывает объявления об аренде.
Переходов на другие страницы нет: Vue обновляет нужные части экрана.
Данные — массив объектов. Один объект соответствует одному объявлению.
У него есть id, название, цена, район, комнаты, площадь, описание и фото.
Пропущенные поля заменяются подписями: например, «Цена не указана».
При установленном ограничении цены объявления без цены не показываются,
потому что проверить их соответствие бюджету невозможно.

4. ГДЕ ЧТО НАХОДИТСЯ

src/main.js — запускает Vue и подключает App.vue и стили.
src/App.vue — логика и разметка всего экрана.
src/style.css — цвета, размеры, расположение карточек и вид на телефоне.
src/data/listings.js — объединяет результат парсера с учебными объявлениями.
src/data/parsed-listings.json — данные, полученные парсером.
public/photos — локальные фотографии, доступные без интернета.
scripts/parse-listings.mjs — парсер сохранённого учебного HTML.
scripts/create-offline.mjs — упаковывает сборку, стили и фото в один HTML.

5. ОСНОВНЫЕ СЛОВА ИЗ КОДА

ref — значение, за изменениями которого следит Vue: текст поиска, фильтр.
v-model — связывает поле ввода со значением в программе.
computed — пересчитывает результат при изменении зависимых значений.
filteredListings — вычисляемый список подходящих объявлений.
filter — перебирает массив и оставляет элементы, прошедшие проверку.
Все условия объединены через &&: каждое из них должно выполняться.
v-for — создаёт карточки по элементам списка.
:key — задаёт карточке уникальный идентификатор.
v-if / v-else — выбирают, что показать: например, список или пустое состояние.
@click — запускает указанное действие при нажатии.
favorites — массив id избранных объявлений.
toggleFavorite — добавляет id в массив либо удаляет, если он уже там.
selectedListing — выбранная квартира. Пока значение null, окно закрыто.
filteredListings.length — количество найденных объявлений.

6. КАК ПОКАЗАТЬ И ОБЪЯСНИТЬ ПАРСЕР

Для запуска нужен Node.js. В терминале папки проекта:
  npm.cmd run parse
Результат: извлечено 3 объявления; обновлён src/data/parsed-listings.json.
Чтобы обновить отдельный офлайн-HTML после парсинга:
  npm.cmd run build

Алгоритм парсера:
1) readFile читает sample-listings.html как текст.
2) matchAll находит блоки script с типом application/ld+json.
3) JSON.parse превращает текст JSON в объекты JavaScript.
4) getListings обходит массивы и @graph и выбирает объекты жилья.
5) map приводит поля к формату приложения, Number преобразует числа.
6) writeFile записывает получившийся массив в JSON-файл.
Если нет нужных блоков или объявлений, скрипт сообщает об ошибке.

JSON-LD — способ хранить структурированные данные внутри HTML-страницы.
В этом проекте HTML искусственный, учебный. Парсер НЕ скачивает объявления
с Авито, Циан или Домклик. Если преподавателю нужен реальный сайт, эта часть
задания пока выполнена не полностью. Не выдавайте учебный пример за реальный.
